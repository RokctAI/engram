**Prioritising** strategic objectives. Asking the right questions:

1.  What is your overall goal?
2.  List all the things that need to be done to achieve that goal. Pick out the key drivers of success.
3.  Identify no more than 3 priority actions that unlocks progress.

```
       ┌────────────────────────┐
 ┌───▶ │   What is your goal?   │───┐
 │     └────────────────────────┘   │
 │                                  ▼
┌────────────────────────┐     ┌────────────────────────┐
│ Prioritise 3 critical  │     │   What has to be done  │
│        actions         │     │      (long list)       │
└────────────────────────┘     └────────────────────────┘
 │                                  │
 └───  ┌────────────────────────┐ ◀─┘
       │     Select the key     │
       │    drivers? (short     │
       │         list)          │
       └────────────────────────┘
```
